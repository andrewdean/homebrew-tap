# andrewdean/homebrew-tap

Homebrew formulae for Andrew Dean's tools.

```bash
brew install andrewdean/tap/surveyor
```

| Formula | What it installs | Source |
|---|---|---|
| `surveyor` | The Surveyor code-intelligence CLI and MCP server, from the prebuilt release archives | [andrewdean/surveyor](https://github.com/andrewdean/surveyor) |

The `surveyor` formula is rendered by `packaging/homebrew/render-formula.sh` in the
Surveyor repository from each release's `SHA256SUMS`; edit the template there, not the
formula here.
